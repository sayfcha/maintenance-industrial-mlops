# Production Predictive Maintenance & MLOps Platform

Portfolio project for reproducible failure classification
and production-oriented ML engineering.

## Dataset

AI4I 2020 Predictive Maintenance Dataset — UCI.
Source: https://doi.org/10.24432/C5HS5C
License: CC BY 4.0.

## Scope

Estimate current failure probability from five numeric measurements
and product type.

Target: Machine failure.
Exclude identifiers and failure-mode labels from model inputs.

## Limitations

Synthetic data. No demonstrated prediction horizon.
Label inconsistencies will be documented during the data audit.
